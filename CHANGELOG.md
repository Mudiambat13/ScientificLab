# Changelog

All notable changes are documented here. The project follows
[Semantic Versioning](https://semver.org/) and the
[Keep a Changelog](https://keepachangelog.com/) format.

## [0.7.0] - 2026-11-12

### Added
- `mathematics.statistics`: descriptive statistics, `describe`, covariance and
  Pearson correlation, `linear_regression` (`LinearFit`), Student-t
  `confidence_interval_mean`, normal distribution. Validated against `scipy.stats`.
- `visualization.plot_histogram`, `plot_regression`.
- README gallery generated by `scripts/make_readme_figures.py`; images are rewritten
  to absolute URLs on PyPI (hatch-fancy-pypi-readme).

## [0.6.0] - 2026-11-12

Phase 6 - Publication.

### Added
- Documentation site (MkDocs Material + mkdocstrings): installation, quick start,
  guides, full API reference. Every documentation code example is executed by the
  test suite.
- GitHub Actions: CI on Python 3.11-3.13 (+ Windows and macOS), a job with the
  oldest supported dependencies, package build and clean-install smoke test,
  docs build; `release.yml` (PyPI Trusted Publishing, TestPyPI dry run, GitHub
  release); `docs.yml` (GitHub Pages); Dependabot.
- `SECURITY.md`, `docs/releasing.md` (versioning policy and release procedure),
  logo, `[project.urls]`, `docs` extra, sdist contents.

### Fixed
- Lower bound `pint>=0.24` was wrong: Pint 0.24.0-0.24.3 cannot be imported on
  Python 3.11. Now `pint>=0.24.4`.
- Tests no longer fail with NumPy 1.26 (`np.trapezoid`) or SciPy < 1.15 (CODATA
  2018 table); comparisons with SciPy's CODATA 2022 values are skipped there.
- Several documentation examples had wrong comments or signatures (found by
  executing them).

### Changed
- Development status: Beta.

## [0.5.0] - 2026-11-11

Phase 5 - Simulations and graphical interface.

### Added
- `simulations`: `simulate_projectile`, `simulate_free_fall`,
  `simulate_harmonic_oscillator`, `simulate_rc_circuit`, `simulate_cooling`,
  `cooling_time_to_reach`, `simulate_string_wave`; `SimulationResult` and
  `WaveResult` containers (method, notes, summary).
- `visualization`: `plot_simulation`, `plot_trajectory`, `plot_wave_snapshots`.
- `gui`: local web interface (`scientificlab-gui`), standard library only;
  loopback binding, per-session token, Host/Origin checks, body size limit.

## [0.4.0] - 2026-11-10

Phase 4 - Scientific Tools.

### Added
- `constants`: `Constant` records (value, unit, uncertainty, source, edition),
  18 constants (CODATA 2022 / SI 2019 / CGPM), `get_constant`, `list_constants`;
  values cross-checked against `scipy.constants`.
- `units` (Pint): shared registry `Q_`/`ureg`, checked `convert`, offset
  temperatures, below-absolute-zero rejection, `with_units` decorator and
  unit-aware physics wrappers. New exceptions `UnitError`,
  `IncompatibleUnitsError`, `UnknownUnitError`.
- `solvers`: `EquationSolver`, `solve_equation`, `SolveResult`, `SystemResult`
  with `exact` / `complete` / `verified` flags; explicit numeric fallback.
- `visualization`: function, data and physics plots (Matplotlib OO API, no
  pyplot state), PNG/SVG/PDF export, pole-aware sampling.
- `mathematics.algebra.parse_equation` (public).
- Dependencies: `matplotlib>=3.8`, `pint>=0.24`.

### Changed
- `algebra.solve_system` reuses the public `parse_equation` (no behaviour change).

## [0.3.0] - 2026-11-09

Phase 3 - Physics Core.

### Added
- `physics.electricity`: `ohms_law`, `electric_power`, `electric_energy`,
  `series_resistance`, `parallel_resistance`, capacitor functions and a series
  RC circuit model (`rc_voltage`, `rc_current`, `rc_time_to_voltage`, ...).
- `physics.thermodynamics`: `heat_energy`, `latent_heat`, `convert_temperature`,
  `ideal_gas`, isobaric / isothermal / adiabatic work, `carnot_efficiency`,
  `thermal_efficiency`, `efficiency_from_heats`.
- `physics.optics`: `snell_refraction`, `critical_angle`, `reflection_angle`,
  `thin_lens_equation`, `lensmaker_focal_length`, `lens_power`, magnifier and
  telescope magnification.
- `physics.waves`: `wave_relation`, string wave speed, `wave_displacement`,
  sound speed, intensity level, `doppler_frequency`, `superpose`,
  `beat_frequency`.
- `physics.fluid_mechanics`: density, pressure, hydrostatic pressure, Pascal's
  principle, Archimedes' principle, flow rates, continuity, Bernoulli.
- `constants`: `SPEED_OF_LIGHT`, `GAS_CONSTANT`, `VACUUM_PERMITTIVITY` (CODATA
  2022), `STANDARD_ATMOSPHERE`, `ZERO_CELSIUS`; cross-checked against SciPy's
  CODATA table in the tests.
- `utils.validation.require_n_given` for relations where any one quantity can
  be the unknown.

### Physical consistency checks
Inconsistent situations raise `PhysicalInconsistencyError` instead of returning
a number: negative resistance, temperatures below absolute zero, efficiency
above 1 or above the Carnot limit, a supersonic Doppler source, an image at
infinity, an unreachable RC voltage, a negative absolute pressure from
Bernoulli. Total internal reflection is reported in the result (a normal
outcome, not an error).

### Notes
- 766 tests; the Phase 3 modules are fully covered (99 % overall). Ruff and MyPy
  (strict) clean.
- Physics functions still use plain floats in SI units; Pint comes in Phase 4.

## [0.2.0] - 2026-11-09

Phase 2 - Mathematics Core.

### Added
- `mathematics.calculus`: `differentiate`, `partial_derivative`,
  `indefinite_integral`, `definite_integral`, `limit`, `taylor_series`,
  `series_sum` (exact, SymPy). Divergent or undefined results raise
  `SolverError` instead of returning `oo`/`nan` silently.
- `mathematics.linear_algebra`: matrix/vector operations, `determinant`,
  `inverse`, `condition_number`, `solve_linear_system`, `eigen_decomposition`.
  Singular matrices raise `SingularMatrixError`; ill-conditioned problems emit
  `IllConditionedWarning`.
- `mathematics.differential_equations`: `solve_ode` (exact first/second order,
  verified by substitution), `solve_ode_numeric`, `solve_second_order_numeric`.
- `mathematics.numerical_methods`: `newton_raphson`, `bisection`, `secant`,
  `linear_interpolation`, `polynomial_interpolation`, `trapezoid_rule`,
  `simpson_rule`, `adaptive_integral`, `numerical_derivative`; each documents
  its convergence conditions and limits.
- `utils`: `SolverError`, `ConvergenceError`, `SingularMatrixError`,
  `IllConditionedWarning`; array validators (`as_vector`, `as_matrix`, ...).
- `algebra.parse_symbol`.

### Changed
- SciPy added as a runtime dependency (ODE integration, adaptive quadrature).

### Notes
- 398 tests, 98 % line coverage; Ruff and MyPy (strict) clean.
- `statistics` is still reserved and not implemented.

## [0.1.0] - 2026-11-08

Phase 1 - Foundation.

### Added
- Project architecture (`src/` layout), `pyproject.toml` (Hatchling), MIT license.
- Quality tooling: Pytest, Ruff (lint + format), MyPy (strict), GitHub Actions CI.
- `scientificlab.utils`: explicit exception hierarchy and input validation.
- `scientificlab.constants.STANDARD_GRAVITY` (exact, 9.80665 m/s**2).
- `scientificlab.mathematics.algebra`: `solve_linear`, `solve_quadratic`
  (stable, real and complex), `polynomial_roots`, `expand_expression`,
  `factor_expression`, `simplify_expression`, `solve_system`.
- `scientificlab.physics.mechanics`: kinematics, dynamics, energy and work
  (SI units).
- Documentation: README, CONTRIBUTING, CLAUDE.md.

### Notes
- Project named **ScientificLab** (the specification's working name was PhysMathLab).
- Only NumPy and SymPy are declared as dependencies; the other libraries of the
  specification are introduced in the phases that use them.
