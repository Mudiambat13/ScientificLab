# ScientificLab

**Mathematical and physics computing toolkit** - algebra, calculus, linear algebra,
differential equations, classical physics, units, an equation solver, simulations
and plots.

ScientificLab favours **scientific accuracy over feature count**. Every function
performs a real calculation, validates its input, documents its units and limits,
and is tested against known reference values. A result that is physically or
mathematically inconsistent is never returned silently: an explicit exception is
raised instead.

- [Install it](installation.md) and run the [quick start](quickstart.md).
- Read the [principles](guide/principles.md) to know what each kind of result means.
- Browse the [API reference](reference/mathematics.md).
- Launch the [graphical interface](guide/gui.md) with `scientificlab-gui`.
